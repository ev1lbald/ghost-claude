# Ghost Claude

Невидимый оверлей-ассистент для macOS. Висит поверх всех окон и по горячей клавише делает скриншот экрана и отвечает. Работает через **вашу подписку Claude** (Pro/Max): запросы идут через официальный Claude Agent SDK, а тот использует ваш вход в Claude Code. Приложение само токены не читает и не хранит.

План проекта: `/mnt/project-files/plan/ghost-claude-plan.md` (в проекте Claude).

## Быстрый старт

```bash
# 1. Один раз войти в Claude своим аккаунтом
npm i -g @anthropic-ai/claude-code   # если ещё нет
claude            # внутри выполнить /login и выбрать «Claude account»

# 2. Проверить, что подписка работает (этап 0)
npm install
npm run spike                        # текст
npm run spike -- ~/Desktop/shot.png  # с картинкой

# 3. Запустить приложение
npm run dev
```

При первом скриншоте macOS попросит доступ: **Системные настройки → Конфиденциальность и безопасность → Запись экрана**, включите Electron (в dev) или Ghost Claude (в сборке) и перезапустите приложение.

Убедитесь, что в окружении нет `ANTHROPIC_API_KEY`: приложение его и так убирает, но в терминале он заставит `claude` работать по ключу.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| ⌘⇧↩ | Скриншот + ответ |
| ⌘⇧I | Фокус на поле вопроса |
| ⌘⇧Space | Показать / скрыть |
| ⌘⇧A | Что ответить (по расшифровке созвона) |
| ⌘⇧R | Новый разговор |
| ⌘⇧ стрелки | Двигать окно |
| ↩ / ⌘↩ в поле | Отправить / отправить со скриншотом |
| Esc | Остановить ответ / скрыть |

## Созвон: расшифровка и подсказки

Вкладка «Созвон» → «● Слушать». Звук собеседника (системный звук Mac) режется на фразы и расшифровывается **локально** моделью Whisper (WebGPU). Наружу ничего не уходит, пока вы не нажмёте «Что ответить» или ⌘⇧A: тогда последние ~4 минуты расшифровки уходят Claude с профилем «Созвон».

- Нужен macOS 13+. При первом запуске macOS спросит разрешение на запись экрана и системного звука.
- Первый запуск скачивает модель с Hugging Face (~300 МБ для small), дальше она лежит в кэше.
- Микрофон (ваши реплики) включается в настройках. Без наушников он будет ловить и собеседника из динамиков.

## Режимы

- **Подписка** (по умолчанию). Расходует лимиты вашего плана, общие с Claude Code и чатом. На Pro держите скриншот поменьше и используйте Haiku/Sonnet.
- **API-ключ** (запасной). Ключ из Claude Console, хранится в связке ключей macOS через `safeStorage`.

Правила Anthropic про подписки менялись в 2026 году. Используйте приложение лично и не раздавайте его с входом через claude.ai: другим людям нужен свой API-ключ.

## Скрытие от записи экрана

Галочка в настройках вызывает `setContentProtection`: окно не видно в скриншотах, записи и демонстрации экрана. Работает не со всеми программами. На собеседованиях и экзаменах, где помощь ИИ запрещена, использование нарушает правила.

## Сборка

```bash
npm run dist   # → dist/*.dmg (без подписи; при первом запуске: ПКМ → Открыть)
```

## Устройство

- `src/main/providers/subscription.ts` — Agent SDK, вход через подписку
- `src/main/providers/apikey.ts` — запасной режим с API-ключом
- `src/main/capture.ts` — скриншот экрана под курсором
- `src/main/index.ts` — окно-оверлей, горячие клавиши, IPC
- `src/renderer` — интерфейс на React
